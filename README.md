This repository contains all 12 experiments listed in the supplied JCS 308 Web Designing Lab manual. Each experiment folder includes source code and a README. Static previews are linked from the root `index.html`.

## Quick start
1. Extract this ZIP.
2. Open `index.html` to browse the experiment index.
3. Open each experiment's `index.html` for its static preview.
4. For React / Node.js experiments, follow the README inside that experiment folder.

## GitHub publishing
Create a public GitHub repository named `web-designing-lab`, upload the contents of this folder (not the ZIP itself), then go to **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save. The site URL will be:
`https://YOUR-GITHUB-USERNAME.github.io/web-designing-lab/`

GitHub Pages can publish the static index and previews. Node.js APIs and MongoDB-backed applications must be run locally or deployed to a backend hosting provider; GitHub Pages cannot run backend servers.
